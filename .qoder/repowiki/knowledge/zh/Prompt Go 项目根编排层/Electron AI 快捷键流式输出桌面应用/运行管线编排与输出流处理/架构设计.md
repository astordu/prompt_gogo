模块以 `run-coordinator.js` 为单一协调中心，维护互斥的活跃 Run 状态、Cancel 快捷键注册/注销、Output Target 有效性校验以及 Loading(`S`) / Ending(`E`) 指示器生命周期；`run-executor.js` 作为高层编排器，串联文本读取、模板变量替换、Provider 查找与校验、SSE 流式请求、`stream-output.pipeToCursor` 缓冲管道和剪贴板 sink，并通过 `AbortController` 实现可中断的取消传播。

依赖方向单向：executor → coordinator → 各 sink（clipboard-sink、run-indicator）→ 系统调用（osascript/Electron clipboard）。所有外部依赖（剪贴板、AppleScript 执行、通知、窗口管理、delay）均通过构造函数注入，便于测试时替换为 mock。

- `output-target.js`：捕获并验证前台应用，防止焦点切换导致写错位置。
- `text-reader.js`：优先通过 Accessibility API 读取选中文本，回退到 Cmd+C 剪贴板。
- `sse-stream.js`：解析 OpenAI 风格的 SSE `data: {choices:[{delta:{content}}]}` 事件流。
- `stream-output.js`：基于字符阈值（30）和时间窗口（200ms）的缓冲管道，支持 AbortSignal 立即停止。
- `clipboard-sink.js`：通过覆盖系统剪贴板 + Cmd+V 模拟粘贴，并在 close() 时条件性恢复原始剪贴板。
- `run-indicator.js`：用原子化“Shift+左箭头选择 + BackSpace 删除”一次性移除指示器，避免逐字删除闪烁。
