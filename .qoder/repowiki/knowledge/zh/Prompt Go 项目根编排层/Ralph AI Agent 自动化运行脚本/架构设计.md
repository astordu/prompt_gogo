该模块由三个 Bash 脚本和一个共享 prompt 模板组成，围绕 `ralph/prompt.md` 这一提示词文件组织：
- `once.sh`：单次执行入口，拉取最近 5 次 git commits 和两类 GitHub issues（ready-for-agent + 所有 open），拼接 prompt 后调用 `run_agent` 执行一次。
- `afk.sh`：循环迭代入口，支持 `max_iterations` 参数，在每次迭代中刷新 ready-for-agent issues 列表，直到无待办或达到上限。
- `cronjobloop.sh`：守护进程包装器，通过 while true 循环每 30 分钟调用 `afk.sh claude 20`，用于 cron 定时调度。
- 三者通过统一的 `ADAPTER` 参数（qodercli|claude|codex）和 `run_agent` case 分支适配不同 AI 客户端，依赖外部工具 `gh`（GitHub CLI）、`git` 以及各 agent CLI。
- 依赖方向单向：脚本 → prompt.md；脚本之间无相互引用，仅 `cronjobloop.sh` 调用 `afk.sh`。
