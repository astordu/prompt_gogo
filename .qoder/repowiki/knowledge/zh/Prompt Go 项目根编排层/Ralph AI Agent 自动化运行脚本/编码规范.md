- 所有脚本统一以 `#!/bin/bash` 开头并使用 `set -eo pipefail` 开启严格错误处理。
- 通过 `case "$ADAPTER" in qodercli|claude|codex)` 模式匹配校验输入参数，非法值输出 usage 并 exit 1。
- AI 客户端调用封装在 `run_agent` 函数内，通过 case 分支根据 ADAPTER 选择具体命令，保持调用点一致。
- GitHub issues 查询统一使用 `gh issue list --state open --json ... --jq '...'` 管道过滤，失败时回退到空数组 `[]` 而非中断流程。
- Git 操作失败时使用 `|| echo "..."` 降级处理，避免单个命令失败导致整个脚本退出。
