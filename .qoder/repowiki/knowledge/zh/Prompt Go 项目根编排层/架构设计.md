根目录不承载业务逻辑，而是作为跨子模块的契约与编排层：
- 入口与依赖：package.json 声明 main='src/main.js'，定义 start/dev/test/lint/typecheck/coverage/verify/dist 等统一脚本，electron-builder 配置产出 macOS DMG。
- 类型与风格：tsconfig.json 对 src/**/*.js 启用 checkJs（noEmit），eslint.config.js 为 src 与 test 分别配置 browser+node 全局与 CommonJS 源类型，确保 electron_app、tests、scripts 共享一致的代码质量约束。
- 运行时编排：electron_app 子模块加载主进程后通过 IPC 桥接渲染器，协调 ShortcutService、RunExecutor、RunCoordinator 完成快捷键→AI 流式输出管线；tests 子模块用 node:test 独立验证 provider/template/shortcut-service/run 等核心逻辑；scripts 子模块提供 Ralph Agent 的一次执行、循环迭代与 cron 守护三种运行方式；docs 子模块集中 ADR 与 Agent 规范。
- 构建产物：electron-builder 仅打包 src/**/* 与 package.json 到 dist 目录，生成 com.promptgogo.app 标识的 Prompt Go 应用。
