- 所有 JavaScript 源码与测试通过 ESLint（@eslint/js）统一校验，--max-warnings=0 禁止警告
- TypeScript 仅用于类型检查（tsc --noEmit + checkJs），不生成 .js 文件，src 与 test 共享 tsconfig.json
- 测试文件采用 node:test 框架，按功能域组织在 test/*.test.js 与 test/run/*.test.js 中
- 环境变量与用户配置通过 electron-store 持久化，Provider 与 Shortcut 配置分离复用
- 文档术语严格遵循 CONTEXT.md 中的词汇表（Template/Variable/Shortcut/Provider 等），避免混用近义词
