模块由三个文件构成清晰的职责分层：
- `settings.html` 是唯一的页面入口，通过 Tailwind CSS CDN + Material Symbols 构建 UI，内嵌 `<script>` 按依赖顺序加载 `provider.js`、`template.js`、`shortcut-draft.js`、`renderer.js`。
- `template.js` 是无框架纯函数库，暴露 `parseTemplate` / `serializeTemplate` / `replaceVariables` / `validateTemplate` 和 `VARIABLES` 常量，同时支持 CommonJS（main 进程）和浏览器全局 `window.templateModule` 两种加载方式。
- `renderer.js` 是渲染进程主逻辑：顶部定义全局状态（`shortcuts`、`providers`、`currentEditingProviderId`），通过 `draftAdapter` 对象将 `shortcutDraftModule.ShortcutDraft` 工作流模块适配到 `window.electronAPI` IPC；模板编辑器基于 `contenteditable` 实现原子 chip（`@variable`），配合自定义补全菜单完成变量插入。
- 数据流向单向：用户输入 → draft 模块状态变更 → `renderDraftSnapshot` 订阅回调 → 更新 DOM；Provider CRUD 直接调用 `window.electronAPI` 并刷新本地数组后重绘表格。
- 依赖方向：`renderer.js` → `template.js`（模板解析）、`shortcut-draft.js`（工作流状态机）、`provider.js`（Provider 表单逻辑）、`window.electronAPI`（IPC 桥接 main 进程）。
