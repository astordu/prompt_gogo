- 每个测试文件顶部声明 'use strict'，并使用 const { describe, test } = require('node:test') 和 const assert = require('node:assert') 引入测试 API。
- 对外部依赖（registrar、store、notifier、outputTarget、text reader、cancel registrar）通过模块内定义的 createFake* 工厂函数构造替身，替身暴露 _trigger/_has/_size/_reject/_throwOn 等测试专用方法用于注入行为和断言。
- 通过 makeCoordinator / makeService 等辅助函数集中组装被测对象及其依赖，使测试用例保持简洁且可复用。
- 测试用例按被测方法或功能域用 describe 分组，每个具体场景一个 test，断言优先使用 assert.strictEqual 和 assert.deepStrictEqual 进行精确比较。
- 异步测试通过返回 Promise 或使用 async/await 编写，错误路径使用 assert.rejects 断言异常。
- settings-theme.test.js 使用 JSDOM 加载 HTML 并注入全局 window/document 及 electronAPI 桥接方法，通过 t.after() 清理注入的全局变量和缓存。
