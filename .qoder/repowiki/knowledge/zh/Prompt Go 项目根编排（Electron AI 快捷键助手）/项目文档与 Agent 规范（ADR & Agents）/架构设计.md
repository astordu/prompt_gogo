文档按职责分为两个子目录：
- `adr/`：采用编号前缀（0001、0002…）的 ADR 文件，每个文件遵循统一的三段式结构——标题、Considered Options（备选方案及否决原因）、Consequences（迁移影响与副作用），用于记录如 @mention 变量语法切换、多 Provider 架构等关键设计决策。
- `agents/`：面向 Agent 的技能/流程文档，包含领域建模指南（domain.md）、GitHub Issue 操作约定（issue-tracker.md）以及分诊标签映射表（triage-labels.md），通过标准化命令和标签字符串让 Agent 能一致地与 GitHub 交互。
依赖方向单向：Agent 文档引用 ADR 作为权威决策来源；代码库中的技能通过读取这些文档来理解领域术语与工作流程，不反向依赖代码实现。
