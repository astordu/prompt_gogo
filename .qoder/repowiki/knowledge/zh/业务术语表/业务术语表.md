### Template（提示模板）
- 定义：一段包含零个或多个变量的提示词文本，与一个全局快捷键绑定。触发时，变量被替换为实际值后发送给 AI。避免使用 Prompt、提示、模板等泛称。
- 别名：提示模板、prompt template

### Variable（变量）
- 定义：模板中的一个命名占位符，触发时被动态值替换。书写语法为 `@变量名`（如 `@select_content`）。一个模板中同一变量可出现多次。避免使用 Placeholder、占位符、token、标记等术语。
- 别名：变量、variable

### Chip（胶囊）
- 定义：变量在模板编辑器中的可视化形态——一个带背景色的内联原子元素，不可部分编辑，选中和删除均以整体为单位。避免使用 Tag、badge、mention 等术语。
- 别名：胶囊、chip

### Completion Menu（候选菜单）
- 定义：在模板编辑器中输入 `@` 后弹出的下拉列表，展示所有可用变量供用户选择。输入字符可过滤候选；无匹配时菜单消失。避免使用 Dropdown、autocomplete、下拉框等术语。
- 别名：候选菜单、completion menu

### Shortcut（快捷键）
- 定义：一个全局键盘组合（如 Control + Option + 9，显示为 `⌃⌥9`），绑定一个 Template 和一个 Provider，在任意应用中可触发。避免使用 Hotkey、热键、keybinding 等术语。
- 别名：快捷键、shortcut

### Run（运行任务）
- 定义：一次由 Shortcut 触发的 AI 文本处理过程。同一时刻最多存在一个活动 Run。避免使用 Task、任务、Process、请求等术语。
- 别名：运行、run

### Output Target（输出目标）
- 定义：Run 触发时所在的应用与编辑位置。一个 Run 的所有状态提示和模型内容只能写入其原始 Output Target。避免使用 Current Focus、当前焦点、Cursor、光标等术语。
- 别名：输出目标、output target

### Provider（模型提供方）
- 定义：一个可复用的 AI 服务连接配置，包含类型（DeepSeek / Ollama / Custom）、连接地址、凭证和模型名。多个 Shortcut 可共享同一个 Provider。避免使用 Service、服务、backend、后端、engine 等术语。
- 别名：模型提供方、provider

### grill-with-docs
- 定义：一种交互式需求分析方法，通过逐步追问确认功能细节和边界条件，最终产出规格文档。常用于复杂功能的方案设计阶段。
- 别名：刨根问底访谈、grill

### to-spec
- 定义：将经过 grill-with-docs 确认的需求转化为结构化规格文档的流程，包括测试决策、接缝设计、用户故事等，并发布到 Issue Tracker。
- 别名：规格生成、spec

### to-tickets
- 定义：将规格文档拆分为可执行的开发工单（tickets），每个工单包含具体的实现步骤和验收标准。
- 别名：工单拆分、ticket

### improve-codebase-architecture
- 定义：代码架构改进流程，通过分析现有架构问题并提出重构方案，通常结合 ADR（架构决策记录）进行决策。
- 别名：架构改进、architecture

### Matt Pocock skills
- 定义：一套基于 Matt Pocock 方法论的 AI 辅助开发技能集，包括 issue tracker 配置、分诊标签、领域文档管理等，通过 AGENTS.md 和 docs/agents/*.md 文件进行配置。
- 别名：技能配置、skills

### pre-push 验证
- 定义：Git pre-push hook 配置的代码质量检查流程，包括 lint、typecheck、单元测试和覆盖率检查（要求 60%+），只有全部通过才能推送代码。
- 别名：预推验证、verify
