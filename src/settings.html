为了让 Prompt Go 正常工作，您需要授予以下权限：

1

辅助功能权限

此权限用于读取和操作选中的文本内容。

系统设置 → 隐私与安全性 → 辅助功能

找到 Prompt Go，勾选启用

2

屏幕录制权限（可选）

某些情况下可能需要此权限来获取屏幕内容。

系统设置 → 隐私与安全性 → 屏幕录制

找到 Prompt Go，勾选启用
